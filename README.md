# Pixora

Pixora is a modern social media web app built with HTML, CSS, JavaScript, Vite, Firebase Authentication, and Cloud Firestore. It includes real-time posts, messaging, profiles, follow system, likes, comments, saved posts, Google sign-in, and a responsive interface designed for both desktop and mobile users.

## Overview

Pixora focuses on a clean and interactive social experience without unnecessary complexity. Users can create accounts, share posts, follow other users, chat in real time, and manage their profile from a simple web interface.

The project is designed as a front-end Firebase application, making it easy to deploy, customize, and extend with more features later.

## Features

- Email and password authentication
- Google sign-in
- Real-time Firestore database
- Create and view posts globally
- Like, comment, save, and share posts
- Follow and unfollow users
- User profile pages with posts and stats
- Real-time messaging
- Emoji and GIF support in chats
- Image sharing in messages
- Profile picture upload and editing
- Settings page
- Saved posts section
- Account logout and delete account option
- Responsive design for desktop and mobile
- Firebase Hosting support

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vite
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting
- Tenor GIF API
